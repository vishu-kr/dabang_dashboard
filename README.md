# Dashboard UI

A responsive dashboard application built with React and CSS, following the provided Figma design. The project includes reusable components, dashboard charts, statistics cards, sidebar navigation, and responsive layouts.

## Tech Stack

- React
- CSS
- Recharts
- React Icons
- Vite
- pnpm

## Prerequisites

Make sure you have the following installed:

- Node.js (v18 or later recommended)
- pnpm

Install pnpm globally if needed:

```bash
npm install -g pnpm
```

## Installation

Clone the repository:

```bash
git clone <https://github.com/vishu-kr/dabang_dashboard.git>
```

Navigate to the project directory:

```bash
cd dabang_dashboard
```

Install dependencies:

```bash
pnpm install
```

## Running the Application

Start the development server:

```bash
pnpm dev
```

The application will be available at:

```text
http://localhost:5173
```

## Additional Libraries Used

### Recharts

Used for dashboard visualizations such as:

- Visitor Insights
- Revenue Analytics
- Target vs Reality

Install:

```bash
pnpm add recharts
```

### React Icons

Used for:

- Sidebar icons
- Header icons
- Dashboard card icons

Install:

```bash
pnpm add react-icons
```
